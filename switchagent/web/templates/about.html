Something went wrong or you have a question?

  1. Open Settings, scroll to Diagnostics and press Copy diagnostics (and Copy logs if it is about an install that failed). Nothing personal is in them: no library contents, no device IDs.
  2. Open a new GitHub issue (a free GitHub account is needed; sign-up takes a minute).
  3. Write what you did, what you expected and what happened instead, and paste the diagnostics under it. A screenshot helps.
